Existing tests this criterion replaces because they assert the very behavior the task changes (for a bug fix, a test that asserts the bug). Each entry is the original test file's path from the repository root and the test's own name, such as {"file": "tests/test_shipping.py", "test": "test_fifty_dollar_order_pays_standard_fee"}. Only a test: criterion may list one, and its named test must fail on the original code and pass after the change. The original-test gate then accepts a failure of these tests only; every other existing test must still pass. Empty when no existing test contradicts the agreed outcome.
