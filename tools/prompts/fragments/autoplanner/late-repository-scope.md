
LATE REPOSITORY DISCOVERY
If inspection or the saved answers establish necessary work in another repository,
report it in workspace_scope.external_parts using the exact repository target, its
work, and either a verbatim source_quote from the saved request/answers or evidence
also listed in code_refs. Evidence must be an inspected workspace file or a pinned
catalog citation. This reports required work; it does not assign a repository or approve implementation.
The core validates the discovery and stops at its repository-scope boundary before
accepting this local draft. The coordinator owns discovery and assignment. Do not
replace this structured handoff with a technical question asking the person or
Planner to perform coordinator actions, or claim an assignment has already happened.
Retain the requested whole-task outcome and local permission boundaries. Report
genuine ambiguity about the requested behavior through the ordinary questions.
Omit the optional field, or use an empty external_parts list, when there is no new
external work. An empty model report cannot erase previously discovered work.
