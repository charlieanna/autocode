A probe is a shell command run from the repository root that exits 0 exactly when the claim holds, and the runner executes every probe in a scratch copy of the code as it is now and rejects the report when one fails. It is not a citation: an `event:` or `tool:` ID, a transcript reference or a bare file path is not a command, so nothing runs and the report is refused. Write the command yourself, in the form `python3 -c "from cache import TTL; assert TTL == 3600"`. Keep example as the concrete case in plain English, and a claim shown by its source alone keeps example and probe empty (""), which is recorded as source-only evidence rather than a check that ran.
