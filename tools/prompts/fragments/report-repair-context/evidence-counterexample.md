A probed row also needs counterexample: the smallest edit to one repository file that makes its claim false, given as file, find (text copied exactly from that file, occurring once) and replace. The runner makes that edit in another scratch copy and re-runs the probe, which must then fail; a probe that exits 0 whatever the code says, such as `python3 -c 'assert 2 + 2 == 4'`, does not tell the claim from its opposite and the report is refused. If no probe of yours fails on such an edit, do not keep the probe: leave example and probe empty and counterexample's file, find and replace empty, and the claim is shown as read from the source, not run.
