Every command a check plan names in backticks (an acceptance criterion's verification_method, a task's validation_plan step) is replayed by the runner as a check that must exit 0. Check a command that must fail (a usage error, a refused input) inside a test, or name it as "run `X` and assert exit N" right after the commands (N/M with one status per command for several), or wrap it so it exits 0 exactly when it fails as it should, for example sh -c 'X; test $? -eq 2'.
