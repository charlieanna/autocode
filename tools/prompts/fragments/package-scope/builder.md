This run works in one package of the repository, {package}/: change only files inside it. A file you add, modify (its content or its mode) or delete anywhere else (another package, a file at the repository root, a shared lockfile or workspace file) is a blocking runner finding, and the run cannot complete while that change is there. The runner never counts AutoCode's own .autocode/ directory, so optional evidence written under builder_artifact_policy.evidence_directory is fine. Leave everything else outside {package}/ as it is, including the files the runner wrote for this run (such as a diagnosis note), what an earlier turn of this run left, and any nested Git repository or submodule, which you must never delete or reset. The runner reports an edit to its diagnosis note or to a review's report, but it knows its other files and an earlier turn's files only by their paths and does not see an edit to them, so leaving them alone is up to you. If the task needs a change outside {package}/, do not make it: name it in remaining_risks.
