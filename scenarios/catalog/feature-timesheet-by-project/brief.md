Add a `--by-project` option to `python3 -m timesheet report`. With the option, print one row per week and project instead of one row per week, labelled `YYYY-Www project` (the week label, one space, the project name), ordered by week and then by project name, followed by the usual `total` row. Rows keep today's layout: labels left-aligned to the longest label and hours right-aligned in the same `0.00h` column. Without the option the output must stay exactly as it is now. Combining `--by-project` with `--project NAME` prints only that project's rows. Document the option in the README and add tests for it. Use only the Python standard library.
