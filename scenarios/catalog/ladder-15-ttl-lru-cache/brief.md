Implement `app.Cache(capacity, clock)` with `put(key, value, ttl)`, `get(key, default=None)`, and `len(cache)`. clock is a caller-supplied monotonic callable returning numeric seconds. Capacity must be a positive integer (bool rejected). TTL must be a positive finite int or float (bool rejected); invalid TTL raises ValueError without changing entries or recency. Entries expire exactly when clock() >= insertion_time + ttl. get returns the default for missing/expired entries and marks a live hit most recently used without extending its TTL. put stores or overwrites a key with a fresh deadline and marks it most recent. Reclaim expired entries before evicting any live entry; if full, evict the least recently used live key. len counts only live entries and must not alter their recency. Values may include None. Tests must inject a fake clock and advance it directly, using no real sleeps.


Use only the Python standard library. Preserve the seed test, add meaningful tests under tests/, and document the public interface and test command in README.md. No external services or real-time sleeps.
