Build the public API `app.DocumentStore(path)` over SQLite, with `create(key, body)`, `read(key)`, and `update(key, body, expected_version)`. Keys are nonempty strings and bodies are strings. Each method returns a dict with exactly key, body, version. New documents start at version 1. A successful update compares the expected version atomically, replaces the body, and increases version by one. Raise `app.ConflictError` (a ValueError subclass) for stale versions or creating an existing key, and KeyError for missing documents. Rejected operations must preserve document contents and versions. Stores using the same path must observe each other's commits; reopening preserves state; separate database paths remain isolated. Concurrent updates with the same expected version permit exactly one success. Validate types and reject bool/noninteger/nonpositive expected versions with ValueError. No external dependencies.


Tests: `python3 -m unittest discover -s tests -t .`. Requires Python 3.11+; standard library only.
