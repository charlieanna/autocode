Implement this project: Build a stdlib-only incremental buildgraph package. topology(graph) accepts a dict mapping node names to lists of dependency names and returns a topological order, always choosing the lexicographically smallest currently ready node. Reject missing dependencies, duplicate dependencies, self edges, and any cycle (including a disconnected cycle) with ValueError. Builder(graph, cache_path).build(sources, compile_fn) requires sources to map exactly every node to a string and calls compile_fn(node, source, dependency_outputs), where dependency_outputs maps only direct dependencies to their compiled string outputs. Return all node outputs as a dict. The first build compiles all nodes in topology order. Reopening with identical graph/sources must reuse the durable JSON cache with no callbacks. A node is rebuilt if its own source, direct dependency list, or any direct dependency output differs from its cached inputs. If a dependency rebuild yields identical output, its dependent may remain cached. Removed nodes must disappear from results/cache. Callback exceptions propagate, and invalid graphs/sources or a failed build must preserve the prior cache byte-for-byte. Persist a successful build atomically; an absent cache means empty, a malformed existing cache raises ValueError without callbacks or rewriting it. Include tests for a diamond graph, cache reuse, transitive changes, and failure recovery. Concurrent builders and real compiler processes are out of scope.

Run tests with `python3 -m unittest discover -s tests -t .`. This is a bounded local engineering benchmark; it requires no network, paid services or real deployment.
