In this Docutils checkout, `:number-lines: 0` on an "include" directive does not work. Including a file with `:literal:` (or `:code:`) and `:number-lines: 0` numbers the included lines from 1 instead of 0, so the first line shows "1". Any other start value works, and `:number-lines:` with no value should keep starting at 1. The "code" directive should accept the same start values. Fix it and add a regression test to the Docutils test suite, which must keep passing (python3 test/alltests.py).
