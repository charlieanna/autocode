Implement this project: Build a SQLite-backed Service(path) for tenant-scoped documents with roles viewer, editor, admin. create_tenant(tenant, owner) creates a tenant and its first admin; duplicate tenant raises ValueError. grant(actor, tenant, user, role) adds or changes membership and revoke(actor, tenant, user) removes membership; both require actor to be an admin of that tenant, reject invalid roles/unknown target users with ValueError for the applicable operation, and forbid removing or demoting the last admin. Grant may add a previously unknown user. put(actor, tenant, key, value) and delete(actor, tenant, key) require editor or admin; get(actor, tenant, key) and documents(actor, tenant) require any membership. put upserts a string document; documents returns a dict keyed by document name. Unknown or unauthorized tenants/documents raise PermissionError before checking existence; an authorized read/delete of a nonexistent document raises KeyError. Membership and data are scoped by tenant even when usernames or document keys coincide. Reopenings preserve state, and two concurrent admins attempting to revoke themselves must leave at least one admin. Calls use trusted caller identities passed by the hosting application; building login/authentication is out of scope. Include public tests for authorized workflows and isolated tenant storage, using only the standard library.
