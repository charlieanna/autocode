Implement this project: Build a local deployment configuration planner, using only Python's standard library and performing no real deployment. plan(manifest, environment) accepts {'services': {name: {'depends_on': [names], 'ports': [integers], 'env': {key: string_template}}}}; all three service fields are optional with empty defaults, and no other fields are allowed. Service names are nonempty strings. Return a list of dicts with name, depends_on (sorted), ports (sorted), and env (resolved mapping), in dependency-first order with lexical tie-breaking among ready services. Reject unknown or duplicate dependencies, any cycle including disconnected cycles, duplicate host ports across or within services, bool/non-integer/out-of-range ports (valid 1..65535), malformed manifest/service structures, and non-string templates or environment values with ValueError. Templates replace ${KEY} using the environment and ${KEY:-default} using default only when KEY is absent (an empty present value is preserved); placeholders may appear inside longer strings, KEY matches [A-Za-z_][A-Za-z0-9_]*, and malformed or unresolved placeholders are errors. Do not mutate either input. write_plan(manifest, environment, path) atomically writes the plan as JSON plus newline, returning the plan; any validation error must leave an existing output byte-identical and create no output if absent. Add a CLI python -m deployment MANIFEST --env ENVIRONMENT --output OUTPUT: both inputs are JSON files, successful writes exit 0, invalid JSON/config exits 2 with a concise stderr error, and preserves prior output. Include public regression tests and useful README usage. Filesystem permission errors need not be mapped to exit 2. No container runtime, credentials, cloud account, or production deployment is required.

Run tests with `python3 -m unittest discover -s tests -t .`. This is a bounded local engineering benchmark; it requires no network, paid services or real deployment.
