Build `app.make_server(host="127.0.0.1", port=0)` returning a standard-library ThreadingHTTPServer that binds the requested address and can be driven with serve_forever/shutdown/server_close. Store items in memory per server instance. All endpoints require a nonempty X-Tenant header; missing/blank tenant returns 401. POST /items with a JSON object containing exactly title (a nonblank string of at most 100 characters) creates an item and returns 201 with {id: positive_integer, title: original_title}. GET /items returns that tenant's items in ascending id order; GET /items/ID returns an item; PATCH /items/ID with the same validated body changes its title and returns 200; DELETE /items/ID returns 204 and an empty body. Unknown paths, missing items, and items belonging to other tenants return 404. POST/PATCH require Content-Type application/json (optional charset parameter accepted) or return 415; malformed JSON or invalid fields return 400. Errors are JSON objects and must never modify items. Successful responses except DELETE use application/json. Item IDs must be unique within a server. Creating a second server yields an empty independent store. Tests use only ephemeral loopback ports, cleanly shut down every server/thread, and never sleep.


Use only the Python standard library. Preserve the seed test, add meaningful tests under tests/, and document the public interface and test command in README.md. No external services or real-time sleeps.
