Build notes, a small note-taking command line in Python that uses only the standard library. `python3 -m notes add TEXT` saves a note and prints `added N`, where N numbers the notes from 1 in the order they were added. `python3 -m notes list` prints every note as `N TEXT`, one per line, in that order. `python3 -m notes search WORDS` prints the notes whose text contains WORDS, ignoring case, in the same format. `python3 -m notes export` prints every note as a JSON array of objects with keys id and text. Notes are kept in the JSON file that the NOTES_FILE environment variable names, or in notes.json in the current directory. A command without its argument, or an unknown command, prints a usage line to stderr, prints nothing to stdout and exits with status 2. Build it as a program of separate workstreams: first a walking skeleton that adds and lists notes end to end, with a test that walks that journey; then search and export, each in its own module under notes/commands with its own test; then a test of the whole journey on the merged product.
