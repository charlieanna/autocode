Build notes, a small note-taking command line in Python that uses only the standard library. `python3 -m notes add TEXT` saves a note and prints `added N`, where N numbers the notes from 1 in the order they were added. `python3 -m notes list` prints every note as `N TEXT`, one per line, in that order. `python3 -m notes search WORDS` prints the notes whose text contains WORDS, ignoring case, in the same format. `python3 -m notes export` prints every note as a JSON array of objects with keys id and text. Notes are kept in the JSON file that the NOTES_FILE environment variable names, or in notes.json in the current directory. A command without its argument, or an unknown command, prints a usage line to stderr, prints nothing to stdout and exits with status 2. Every test points NOTES_FILE at a temporary file, so running the tests leaves nothing in the project. Build it as a program of separate workstreams: first a walking skeleton that adds and lists notes end to end, keeping the notes through one module, notes/store.py, with tests/test_skeleton.py walking that journey (tests/ is a package, with tests/__init__.py); then search and export, each in its own module, notes/commands/search.py and notes/commands/export.py, with its own test, tests/test_search.py and tests/test_export.py; then tests/test_journey.py, a test of the whole journey on the merged product.
