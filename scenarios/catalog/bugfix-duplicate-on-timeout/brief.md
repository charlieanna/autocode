Occasionally we renew the same domain twice after a timeout: the expiry advances by two years and the customer is billed twice. It only happens when the registry is slow. Figure out why and fix it. Before you change anything, write the root cause to docs/bugs/duplicate-renew.json with the fields observed, reproduction, root_cause, affected_paths (the files involved) and invariant (the rule the fix must uphold). Then fix the cause, not the symptom: one logical renew must never extend the expiry twice, and a renew that timed out before the registry saw it must still be retried. Add regression tests that fail on the current code and pass after the fix. Keep the RenewClient API and the standard library only.
