Implement `app.paginate(rows, limit, cursor=None)`. rows is a list of JSON-like dictionaries with unique integer id and integer created_at; preserve every field in returned rows. Return exactly `{"items": [...], "next_cursor": token_or_None}`. Order ascending by (created_at, id) regardless of input order. limit must be an integer in 1..100, rejecting booleans with ValueError. A non-null cursor is a nonempty opaque string identifying the last emitted ordering key; a continuation returns only rows strictly after that key. Emit a nonempty string next_cursor only when there are more matching rows. Reject malformed or invalid cursor tokens with ValueError. The cursor must work with a new list containing earlier insertions or deletions, without using list offsets or retaining process-global pagination state. Never mutate rows or their dictionaries. Empty input returns an empty page with a null cursor.


Tests: `python3 -m unittest discover -s tests -t .`. Requires Python 3.11+; standard library only.
