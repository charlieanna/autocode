Implement this project: Build the local ledger package described here using only Python's standard library. Ledger(path) opens or creates a SQLite-backed ledger; separate instances and threads must safely share the same file. create(account, balance=0) creates a named account; duplicate names or a negative/non-integer initial balance raise ValueError. balance(account) returns its integer balance and raises KeyError for unknown accounts. transfer(key, source, target, amount) returns True for a newly committed transfer and False for replay of exactly the same key and arguments. A reused key with different arguments raises ValueError. An amount must be a positive integer (bool is not accepted), source and target must differ, unknown accounts raise KeyError, and insufficient funds raise ValueError. Failed transfers reserve no idempotency key. Transfers must be atomic, preserve total funds, prevent negative balances under concurrency, and survive reopening the file. Identical concurrent requests commit once. Include public regression tests. No HTTP API, external bank, or floating-point currency is in scope.
