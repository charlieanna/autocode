Add refunds to the shop package. Write shop/refunds.py with refund(order, amount_cents, now), where now is a Unix timestamp in seconds. A refund is allowed until the end of the 30th store calendar day after the store calendar day of delivery: an order delivered on March 1 in store time can be refunded until 23:59:59 on March 31 in store time. Store time is described in README.md. An order that has not been delivered yet (delivered_at is None) can be refunded at any time. Several partial refunds are allowed, but the total refunded on an order must never exceed what was paid for it. Disputed orders cannot be refunded. amount_cents must be a positive integer. When a refund is not allowed, raise shop.refunds.RefundRefused with a short reason and leave the order unchanged; when it is allowed, append the amount to order.refunds and return how many cents can still be refunded. Add tests for these rules.
