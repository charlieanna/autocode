Implement this project: Build safezip.extract(zip_path, destination, max_bytes=1048576), using only the standard library. Return the sorted POSIX relative paths of extracted regular files. Accept nested directories, Unicode filenames, and empty files. destination's parent must already exist, destination must be absent or an empty directory, and no existing component of destination's absolute path may be a symlink. Reject unsafe or malformed archives with ValueError, leaving an existing destination and all surrounding files unchanged; if destination was absent it must remain absent on rejection. Validate all entries before publishing a staged extraction. Reject absolute paths, Windows drive prefixes, backslashes, '.', '..' or empty interior path components, duplicate names (file and directory forms count as the same name), symlinks and non-regular special files, and file/directory prefix collisions. A trailing slash marks a directory and is allowed. max_bytes is a nonnegative integer excluding bool and bounds the total uncompressed regular-file bytes across the whole archive, with exact-limit extraction allowed. Reject CRC failures and corrupt ZIP data. Never overwrite an existing nonempty destination. Include public tests and avoid network access. Concurrent modification of parent directories and ZIP encryption support are out of scope.
