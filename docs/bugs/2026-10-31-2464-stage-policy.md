# Reachable economical stage policies (#2464)

This slice enables compact eligibility for new joint-planning bug fixes and exposes
`--review-routing combined` through the public CLI/project configuration. Saved
runs retain their policy. Combined review uses the configured Completion Reviewer
model, effort and independent session; its disclosure is hashed into the displayed
plan and activation requires that exact approval. Separate review remains the
default. Regression, changed-code evidence and independence checks still apply.

New runs snapshot conservative sensitive-path defaults unless the project supplies
its own list. Sensitive file names and directories keep full planning. Requests
that prescribe test identifiers also keep full planning: the compact compiler
binds diagnosis cases, and the Planner must explicitly bind arbitrary requested
names. The compact draft now retains authenticated source citations, source
constraints, every Requirements row in the Builder task and the saved test command.
