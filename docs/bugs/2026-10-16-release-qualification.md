## Packaging defect and fix

`npm exec --yes --package=@vscode/vsce -- vsce package --out "$OUT"` failed:
VSCE could not resolve the README's attribution link because the extension had
no repository metadata. Repository metadata alone would resolve links against
the repository root, so the subdirectory README now uses explicit GitHub links.

The fix pins VSCE 4.0.0, adds `npm run package`, includes the root Apache license
during the build, and restricts the distributable to the bundled entry point,
icon, README, license and third-party notices. CI packages a VSIX as a regression
check. The actual package passed; an independent ZIP inspection verified the
entry point and license bytes, notice and icon, and absence of source, source
maps, node_modules and task state. Eight entries, 47,996 bytes; artifact SHA-256
`d7e0ba198d880b496c6db6e81e110ac7effc2522c380fa83c2bf252132b01c34`.
