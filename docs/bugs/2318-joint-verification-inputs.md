# Independent access to joint candidate inputs (#2318)

The recovered three-repository TUI run passed native joint proof and protected replay (20 candidate cases, 16 with the sealed originals), but independent validation could not establish exact candidate-copy equality. The authoritative `.autocode/candidate-inputs.json` and its trees were absent from the isolated command workspace and clean replay. Completion review correctly retained AC4 as unverified and requested another validation; repeating the model could not repair the missing inputs.

A lower-level input adapter now copies only that manifest and its named local candidate trees. Every source must have the fixed `.autocode/candidate-inputs/SLUG` shape, match `repositories.json` and its `repos/SLUG` destination, contain ordinary files, and reproduce the coordinator's full content/executable fingerprint. Symlinks, escapes, control data, missing or corrupt payloads and inconsistent mappings are rejected. Other run data is not copied. Capture seals the additional files and checks both original and retained identities before execution. Clean replay receives the same checked payload, and execution-cache identity includes it, so changed or resealed input cannot reuse a previous capture or cached comparison.

The regression executes the exact-tree comparison in both copy paths, verifies that an extra delivered file fails, and rejects unsafe, tampered, resealed and injected inputs. The actual retained three-repository source also passes comparison in a separate disposable copy. This supplemental check changes no native task state or completion credit. The live run still requires a fresh independent verdict, automatic publication and exact-PR-head verification.

Focused Linux consumer checks cover source copying, selected source snapshots, clean replay and execution scheduling. A consumer requiring controller Git metadata initially failed in the archive-only harness and passes in an initialized disposable Git checkout; failed attempts remain retained. macOS supervised source checks are not counted as Linux evidence. AutoCode source was fixed directly, not by the model under verification.
