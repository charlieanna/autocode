# Original obligations at completion

A real diagnosed bug-fix run reached completion after its named regression tests
passed. Independent evaluation still rejected behavior explicitly requested in
the original task. The approved draft represented narrower examples and omitted
an observable public requirement. That completed run remains a false completion.

The human-task authority policy now reaches planning, the Tester, and both
completion review routes. It requires checking the original obligations against
actual assertions and public observations, including representative and partial
boundary conditions. Approval of a model-written draft is not an implicit waiver
of omitted human requirements. Existing later milestones remain pending at a
checkpoint; final completion needs the whole requested outcome.

Concrete in-scope defects remain blocking findings. Missing approved coverage
uses the existing contract correction and re-approval path. No new report field,
run-state key, benchmark-specific condition, or hidden evaluator input is added.
Prompt tests establish this instruction contract, not model compliance. A fresh
real qualification is still required; failed candidates are never resumed or
edited to turn their retained results into passes.
