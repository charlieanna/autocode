# OpenCode 2.x launch (#444)

Homebrew `opencode` is 2.x. `opencode --version` prints `opencode v2.0.20`, and `opencode run` rejects `--dir` and `--variant`. A shared background server would run tools outside the stage process tree, so a 2.x stage uses `--standalone` and the workspace as its working directory. Reasoning effort is `provider/model#effort`.

1.x keeps `--dir` and `--variant`. The saved transport identity includes the version string, so a resume does not silently change major versions.

OpenCode 2 nests a shell exit at `part.state.metadata.metadata.exit`. A non-integer `metadata.exit` is still not command evidence, even if a nested integer is also present.

Strict tool containment and verified visual delivery stay qualified only for OpenCode 1.18.33. A 2.x binary fails those checks closed until they have their own conformance pass.
